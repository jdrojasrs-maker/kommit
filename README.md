# Doubly Linked List Challenge

Implementación de una lista doblemente enlazada en .NET con soporte para operaciones de inserción, búsqueda y eliminación de duplicados.



## Execution Instructions

Sigue estos pasos para clonar y ejecutar el proyecto:

1. **Clonar el repositorio**:

   git clone https://github.com/jdrojasrs-maker/kommit.git

2. **Navegar al directorio del proyecto**:

	cd kommit\technical-challenge

3. **Abrir el proyecto en tu IDE favorito** (Visual Studio, Visual Studio Code, etc.).

4. **Ejecutar el proyecto**:
   - Para ejecutar la aplicación, puedes usar el comando `dotnet run` en la terminal o ejecutar el proyecto desde tu IDE.
